# **App Name**: MoneyGo: Live Shop

## Core Features:

- Seller Shopfront: Sellers can create a profile and display products or videos for sale, plus shipping and pricing.
- TikTok-Style Feed: Implement the video browsing using vertical swipes like in the TikTok app
- Buyer/Seller Chat: Buyers can initiate chat with sellers.
- AI Product Descriptions: Generate compelling product descriptions based on input details.
- Secure Payments: Enable buyers to purchase products directly via secure payment options.
- Landing Page: Attractive landing page.
- Category Section: Navigate across different available product categories on the app

## Style Guidelines:

- Primary background: Black (#000000) for a dark modern theme.
- Accent color: Red (#FF0000) for buttons and highlights.
- Text color: White (#FFFFFF) for readability on the dark background.
- Header font: 'Poppins' (sans-serif) Bold (28-36px) for titles.
- Body font: 'Inter' (sans-serif) or 'Nunito' (sans-serif) (14-18px) for readability, including form inputs
- Button font: 'Poppins' (sans-serif) SemiBold, uppercase optional.
- Collapsible sidebar for smaller screens and a mobile-first responsive design.
